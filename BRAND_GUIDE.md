# C0DL3 Brand Guide

## Project Overview

**C0DL3** is a production-grade zkSync hyperchain implementation featuring elite-level privacy through STARK proofs, designed for maximum security, speed, and user autonomy.

---

## Core Strengths

### 1. **Elite Privacy Architecture**
- STARK-based zero-knowledge proofs using `winter-crypto`
- Always-on privacy by default (100% privacy level)
- Configurable privacy dimensions: amount, balance, sender, recipient, timing
- Cross-chain privacy support
- Production-grade cryptography (ChaCha20Poly1305, Blake3)

### 2. **Technical Excellence**
- Multi-layer privacy system (Contract, ZK, ASP layers)
- Modular proof generation system
- Performance-optimized parallel proof generation
- Comprehensive privacy metrics and compliance tracking

### 3. **Validator Ecosystem**
- ELDERADO Genesis Collection (limited validator NFTs)
- HEAT/COLD token system with deflationary mechanics
- 20 COLD token hard cap with governance model

### 4. **Production-Ready Infrastructure**
- zkSync hyperchain compatibility
- CN-UPX/2 mining algorithm for Fuego compatibility
- Real-time privacy monitoring
- Regulatory compliance integration

---

## Core Ideologies

### 1. **Privacy by Default**
Privacy is not an option—it's a fundamental right. Maximum privacy is always enabled.

### 2. **Open and Accessible**
While maintaining elite security, C0DL3 remains accessible to all users and validators.

### 3. **Code is Law**
Decentralized governance through on-chain mechanisms and validator consensus.

### 4. **Performance and Elegance**
Heavy-duty security doesn't mean sacrificing speed or clean user experience.

### 5. **Sustainable Growth**
Deflationary tokenomics and long-term reward distribution (5-10 year cycles).

---

## Visual Identity

### Design Philosophy
**Heavy, Fast, Clean: The C0DL3 Aesthetic**

- **Heavy**: Substantial, robust security indicators

- **Clean**: Minimal clutter, maximum impact

## Typography

### Primary Typeface
**Inter** or **SF Pro Display** (system fonts for performance)

### Hierarchy
- **H1**: 48-64px, Extra Bold (900)
- **H2**: 36-48px, Bold (700)
- **H3**: 24-32px, Semi-Bold (600)
- **Body**: 16-18px, Regular (400)
- **Small**: 14px, Regular (400)
- **Code**: 14px, Mono, Medium (500)

### Characteristics
- Clean, geometric sans-serif
- Excellent readability at all sizes
- Support for technical terminology

## UI Components Styling

### Buttons
- **Primary**: Solid fill, rounded corners (8px radius)
- **Secondary**: Outline, thin border (2px)
- **Destructive**: Dark red trim (`#991B1B`)
- **Hover**: Subtle scale (102%) and glow effect

### Cards/Containers
- **Surface**: Semi-transparent background (opacity 80-90%)
- **Border**: 1px solid, subtle (10% opacity on primary)
- **Shadow**: Deep, soft shadows for depth
- **Hover**: Gentle lift effect

### Input Fields
- **Background**: Surface color
- **Border**: Dark red trim on focus (`#991B1B`)
- **Placeholder**: Secondary text color, lower opacity
- **Active**: Subtle glow using primary color

### Progress Indicators
- **Track**: Surface bright color
- **Fill**: Primary color with gradient
- **Dark Red Trim**: Accent for important actions

## Visual Assets

### Icons
- **Style**: Line-based, minimal (2px stroke)
- **Corner Radius**: Slightly rounded (4px) for friendliness
- **Weight**: Medium (regular 400 equivalent)

### Illustrations
- **Style**: Isometric or flat 2D
- **Palette**: Monochromatic with dark red accents
- **Complexity**: Simple geometric shapes

### Screenshots/Code Blocks
- **Theme**: Dark with chosen color scheme
- **Syntax Highlighting**: Match primary/secondary colors
- **Border**: Subtle, rounded corners

## Application Guidelines

### Website
- Choose **Deep Space** or **Carbon Fiber** for main site
- Dark red trim on call-to-action buttons
- Clean, spacious layouts (1200px max width)
- Smooth animations (max 300ms transitions)

### Documentation
- Readable code blocks with chosen theme
- Consistent heading hierarchy
- Sidebar navigation with dark red accent indicators
- **Obsidian Core** recommended for developer docs

### Marketing Materials
- Use **Steel Forge** or **Velvet Night** for premium feel
- Heavy use of dark red trim for emphasis
- High contrast for accessibility
- Minimal copy, visual-first approach

### Terminal/CLI
- **Terminal Matrix** theme recommended
- Green on black with dark red accents
- Monospace font throughout
- Clean ASCII art possible

---

## Accessibility

### Contrast Ratios
- All text must meet WCAG AA standards (4.5:1)
- Dark red trim used carefully to maintain readability
- Interactive elements have clear hover states

### Color Blindness
- Never rely solely on color to convey information
- Use icons, labels, and patterns alongside color
- Dark red chosen for visibility across all forms of color blindness
